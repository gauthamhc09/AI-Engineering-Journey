# Chapter 21 – Advanced Pattern Printing

## Problem-Solving Strategy

Never memorize patterns.

Instead ask:

1. How many rows?
2. How many columns per row?
3. What should be printed?

## Rules

- Outer loop → Rows
- Inner loop → Columns
- Inner loop can depend on the current row.
- Print values may depend on the row or column.

## Common Patterns

- Growing triangle
- Inverted triangle
- Number triangle
- Alphabet triangle
- Combined patterns
- Centered pyramid

## Real-World Applications

- Matrices
- Images
- Grids
- Tables
- Variable-length datasets

## AI Applications

- Token processing
- Variable-length sequences
- Batch → Sample → Token iteration
- Matrix reasoning

## Best Practices

- Solve visually first.
- Find the rule.
- Then write the loops.
- Avoid memorization.

## Interview Questions

1. How do you approach an unknown pattern?
2. What determines the inner loop?
3. Why are nested loops useful?

## Key Takeaway

Pattern printing is not about stars—it is about learning to identify rules and translate them into algorithms.
