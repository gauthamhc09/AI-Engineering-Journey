# Chapter 10 - Mini Project (Student Information System)

## 🎯 Objective

Build a console-based Student Information System by combining all concepts learned in Module 1.

---

# Concepts Used

- Variables
- Data Types
- Input & Output
- Operators
- Strings
- Type Casting
- Comments
- f-Strings

---

# Project Flow

```
Welcome

↓

Read Student Details

↓

Read Marks

↓

Calculate Total

↓

Calculate Percentage

↓

Determine Pass Status

↓

Display Report
```

---

# Features

- Accept student information
- Read marks for multiple subjects
- Calculate total and percentage
- Display formatted output
- Show pass status using a Boolean expression

---

# Sample Calculations

```python
total = python_marks + ai_marks + math_marks

percentage = total / 3

passed = percentage >= 35
```

---

# Formatting Output

```python
print(f"Percentage : {percentage:.2f}")
```

Displays the percentage with two decimal places.

# AI Connection

This project demonstrates the same Input → Process → Output flow used in AI applications.

Examples:

- User enters a prompt.
- Program validates and converts input.
- AI model processes the prompt.
- Result is displayed to the user.
