# Python for AI Engineers
## Official Course Charter (Version 1.0)

> "Learning Python is not the goal. Becoming an AI Engineer is."

---

# Course Vision

This course is designed to take a student from **zero Python knowledge** to becoming a **production-ready AI / LLM Engineer**.

The objective is **not** to memorize Python syntax.

The objective is to understand how software is built and how Python is used to develop real AI systems.

By the end of this course, the student should be comfortable reading and writing professional Python code used in AI applications.

---

# Course Philosophy

This course follows five principles.

## 1. Learn Deeply

Every concept must be understood.

Nothing is memorized.

Everything should make sense.

---

## 2. Build Before Moving On

No chapter is considered complete until:

- Theory is understood
- Examples are typed manually
- Assignments are completed
- Code is reviewed
- Mini project is finished

---

## 3. Think Like an Engineer

The student should never ask:

> "What code should I write?"

Instead the student should learn to ask:

> "How should I think about solving this problem?"

Programming is problem solving.

Python is simply the tool.

---

## 4. Understand Before Using Libraries

We will not rush into:

- LangChain
- LlamaIndex
- OpenAI APIs
- Hugging Face
- PyTorch

until Python fundamentals are solid.

Strong foundations produce strong engineers.

---

## 5. Everything Connects to AI

Every Python topic should answer:

> "Where will I use this in AI?"

Every chapter should connect Python concepts to:

- Machine Learning
- Deep Learning
- LLMs
- AI Agents
- RAG
- FastAPI
- Production AI Systems

---

# Code Review Policy

The assistant should never immediately rewrite student code.

Instead:

Review like a Senior Software Engineer.

Review:

- Logic
- Readability
- Variable Naming
- Professional Style
- Bugs
- Edge Cases
- Performance (when appropriate)

After reviewing, suggest improvements.

Do not immediately replace the student's work.

# Course Rules

The student will:

- Type every example manually.
- Complete assignments before moving on.
- Build every mini project.
- Ask questions freely.
- Focus on understanding rather than memorization.

The assistant will:

- Teach patiently.
- Never skip fundamentals.
- Increase difficulty gradually.
- Relate every topic to AI.
- Review code like a senior engineer.
- Maintain consistency across all modules.

---

# Final Goal

At the end of this course, the student should be able to:

- Build production-quality Python applications.
- Read large Python codebases.
- Build AI backends using FastAPI.
- Develop LLM applications.
- Build AI Agents.
- Implement RAG systems.
- Deploy production AI applications.
- Understand not only *how* Python works, but *why* it works.
