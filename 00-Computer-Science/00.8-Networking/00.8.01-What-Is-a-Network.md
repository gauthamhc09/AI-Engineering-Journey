# Module 00.8.01 --- What Is a Network?

## Learning objective

Understand what a computer network is, why networks were developed, how
devices communicate, and what happens when two devices exchange data.

## 1. What is a computer network?

A **computer network** is a collection of two or more computing devices
connected so they can exchange data and share resources.

Devices can include: - Desktop computers and laptops - Smartphones and
tablets - Servers - Printers - Routers and switches - Internet of Things
(IoT) devices

A network allows independent computers to communicate and work together.

## 2. Why were networks developed?

Without networks, computers would largely operate independently. Sharing
files, information or hardware would require inconvenient methods such
as physically moving storage media.

Networks address several needs:

  -----------------------------------------------------------------------
  Purpose                             Example
  ----------------------------------- -----------------------------------
  Communication                       Sending messages between computers

  Resource sharing                    Sharing printers and storage

  Data sharing                        Transferring documents

  Centralised services                Accessing a shared database

  Distributed computing               Multiple computers contributing to
                                      a workload
  -----------------------------------------------------------------------

The central idea is that computers can cooperate rather than remain
isolated.

## 3. How are computers connected?

Devices need a communication medium through which signals can travel.

### Wired networks

Examples: - Ethernet over copper cable - Fibre-optic cable

Electrical signals travel through copper cables. Light pulses carry
information through fibre-optic cables.

### Wireless networks

Examples: - Wi-Fi - Bluetooth - Cellular networks such as 4G and 5G

Wireless communication uses electromagnetic radio waves.

**Important:** Wi-Fi is not the internet. Wi-Fi is a technology for
connecting devices to a local wireless network. That network may or may
not have internet access.

## 4. What actually travels between computers?

Information is represented as bits. During transmission, those bits are
represented by physical signals.

For example, using ASCII:

  Character     Decimal Binary
  ----------- --------- ----------
  H                  72 01001000
  E                  69 01000101
  L                  76 01001100
  L                  76 01001100
  O                  79 01001111

The text `HELLO` can therefore be represented as:

``` text
01001000 01000101 01001100 01001100 01001111
```

At a high level, communication works like this:

1.  The sender's application creates data.
2.  The data is represented in a suitable binary format.
3.  Networking hardware transmits signals representing the bits.
4.  The receiving hardware detects the signals.
5.  The receiver reconstructs the bits.
6.  The receiving application interprets the data.

Examples of physical signals: - Electrical signals on copper cables -
Light pulses in fibre-optic cables - Radio waves in wireless
communication

## 5. Decoding versus decryption

These terms are different:

-   **Decoding** interprets encoded data and converts it into the
    intended representation.
-   **Decryption** uses a cryptographic key to turn encrypted data into
    readable data.

Not all data is encrypted, but secure network communication commonly
uses encryption.

Data is also commonly divided into smaller units for transmission. In IP
networking, these units are called **packets**. Protocols and mechanisms
determine how packets are transported and, where necessary, reassembled.

## 6. How does a computer know where to send data?

A network needs ways to identify destinations and deliver data.

Three important concepts are:

  -----------------------------------------------------------------------
  Concept                             Purpose
  ----------------------------------- -----------------------------------
  MAC address                         Identifies a network interface at
                                      the local network-link level

  IP address                          Provides logical addressing for
                                      communication across IP networks

  Port number                         Identifies an application or
                                      service endpoint on a device
  -----------------------------------------------------------------------

These concepts are studied separately in this module.

Communication requires both a way to transmit data and a way to identify
the intended destination.

## 7. LAN, WAN and the internet

### LAN --- Local Area Network

A LAN connects devices within a limited area, such as: - A home - An
office - A computer laboratory - A campus

Devices on a LAN can communicate with each other even if the internet
connection is unavailable, provided the local network and required
services are functioning.

### WAN --- Wide Area Network

A WAN connects networks over larger geographical distances, such as
across cities or countries.

### Internet

The internet is a global system of interconnected networks. It is not
one central computer or one giant server.

A useful mental model: - LAN: a local network. - WAN: a network
connecting geographically separated networks. - Internet: a global
interconnection of networks.

## 8. Bandwidth and latency

-   **Bandwidth** describes the capacity of a communication link to
    transfer data per unit of time.
-   **Latency** describes the time taken for data to travel between
    endpoints or for a communication operation to complete.

They are related to performance but are not the same thing.

## 9. Connection to backend and AI systems

A modern application may contain a React frontend, a FastAPI backend, a
database and external AI services. These components may run on different
machines and communicate over networks.

For example:

``` text
React frontend
      |
      v
FastAPI backend
      |
      +----> LLM provider API
      +----> Embedding API
      +----> Vector database
      +----> PostgreSQL
```

Networking makes it possible for these independent components to work
together. Each connection introduces considerations such as latency,
failures, timeouts, security and data transfer.

## 10. Key takeaways

-   Networks connect devices so they can exchange data and share
    resources.
-   Data is represented as bits and transmitted using physical signals.
-   Wired and wireless networks use different transmission media.
-   LANs cover limited areas; WANs connect networks over larger
    distances.
-   The internet is a global network of interconnected networks.
-   Addressing is needed to direct data towards the correct destination.
-   Bandwidth and latency are different performance measures.
