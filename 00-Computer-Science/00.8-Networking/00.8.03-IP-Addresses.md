# Module 00.8.03 --- IP Addresses

## Learning objective

Understand what IP addresses are, why they are needed, how IPv4 and IPv6
are represented, how private and public addressing differ, and how IP
addressing applies to local development and cloud deployments.

## 1. What is an IP address?

IP stands for **Internet Protocol**.

An **IP address is a logical address assigned to a network interface and
used to identify it for communication over an IP network.**

IP addressing helps a sender specify a destination and helps network
infrastructure route packets towards that destination.

A device can have multiple network interfaces and multiple IP addresses.
An IP address is not permanently attached to the physical computer
itself.

Example:

``` text
Computer A: 192.168.1.10
Computer B: 192.168.1.20
```

## 2. Why are IP addresses needed?

IP addressing supports three important functions:

1.  **Identification:** Provides logical addresses for network
    interfaces.
2.  **Destination addressing:** Allows a sender to specify where an IP
    packet should go.
3.  **Routing:** Helps routers forward packets towards destinations
    across interconnected networks.

An IP address identifies a network destination. It does not, by itself,
identify which application should receive the data. Port numbers help
identify application or service endpoints.

## 3. IPv4 structure

IPv4 is Internet Protocol version 4.

An IPv4 address contains 32 bits, represented as four decimal groups
called octets.

Example:

``` text
192.168.1.10
```

Each octet contains 8 bits and can represent a decimal value from 0 to
255.

  Octet     Decimal value Binary
  ------- --------------- ----------
  1                   192 11000000
  2                   168 10101000
  3                     1 00000001
  4                    10 00001010

The complete binary representation is:

``` text
11000000.10101000.00000001.00001010
```

Why is each octet between 0 and 255?

An octet has 8 bits, so it can represent:

``` text
2^8 = 256 values
```

Those values range from 0 through 255.

The total number of possible IPv4 address combinations is:

``` text
2^32 = 4,294,967,296
```

That is approximately 4.29 billion combinations.

## 4. Network portion and host portion

An IPv4 address is divided into a network portion and a host portion
according to its subnet mask or prefix length.

Example:

``` text
IP address:  192.168.1.10
Subnet mask: 255.255.255.0
CIDR:        /24
```

With `/24`: - First 24 bits represent the network prefix. - Remaining 8
bits represent the host portion.

Conceptually:

``` text
192.168.1 | 10
 Network    Host
```

For the same `/24` subnet:

``` text
192.168.1.10
192.168.1.20
```

These addresses belong to the same subnet.

But:

``` text
192.168.2.20
```

belongs to a different `/24` subnet.

A computer generally sends traffic for destinations outside its local
subnet to a router, commonly called its **default gateway**.

### CIDR notation

CIDR stands for Classless Inter-Domain Routing.

The `/24` in `192.168.1.10/24` indicates that the first 24 bits are the
network prefix.

  CIDR   Subnet mask       Total IPv4 addresses
  ------ --------------- ----------------------
  /24    255.255.255.0                      256
  /16    255.255.0.0                     65,536
  /8     255.0.0.0                   16,777,216

These are total address counts. Conventional IPv4 subnets reserve
certain addresses, so the number of assignable host addresses is usually
smaller.

## 5. Private IP versus public IP

### Private IP addresses

Private IPv4 addresses are used inside private networks such as homes,
offices and internal cloud networks.

The three reserved private ranges are:

  Range                            CIDR
  -------------------------------- ----------------
  10.0.0.0 -- 10.255.255.255       10.0.0.0/8
  172.16.0.0 -- 172.31.255.255     172.16.0.0/12
  192.168.0.0 -- 192.168.255.255   192.168.0.0/16

Private addresses are not globally unique and are not directly routable
across the public internet.

Different homes or organisations can reuse the same private IP
addresses.

### Public IP addresses

Public IP addresses are used for addressing across the public internet.
Internet service providers and network operators provide public internet
connectivity.

A home network commonly uses private addresses internally and a
public-facing address for internet connectivity.

## 6. NAT --- Network Address Translation

NAT translates network addresses, commonly allowing devices with private
IP addresses to communicate with external networks using a public-facing
IPv4 address.

Example home network:

``` text
Laptop:      192.168.1.10
Smartphone:  192.168.1.11
Smart TV:    192.168.1.12
```

The router can translate outgoing traffic to use its public-facing
address and track connection information so returning traffic reaches
the correct internal device.

This commonly allows multiple home devices to share one public IPv4
address.

Some ISPs also use Carrier-Grade NAT (CGNAT), adding another translation
layer within the ISP network.

## 7. Localhost and loopback

`localhost` is a hostname that refers to the current computer.

Common loopback addresses:

  IP version   Loopback address
  ------------ ------------------
  IPv4         127.0.0.1
  IPv6         ::1

Example:

``` text
http://localhost:8000
```

A React application can call a FastAPI server running on the same
computer through the loopback interface.

The traffic does not need to travel over the physical Wi-Fi network or
public internet.

**Important:** If a browser on your laptop calls `localhost`, it refers
to your laptop. It does not refer to a backend running on a different
machine.

## 8. How does a device get an IP address?

### Static IP configuration

A static IP is manually configured or reserved so that a device
consistently uses a predictable address.

This is useful for infrastructure that other systems need to locate
reliably.

### Dynamic IP configuration and DHCP

DHCP stands for Dynamic Host Configuration Protocol.

It automatically provides network configuration to devices. A typical
configuration includes: - IP address - Subnet mask or prefix - Default
gateway - DNS server information

A simplified flow:

``` text
Device joins network
       |
       v
Requests configuration
       |
       v
DHCP server offers configuration
       |
       v
Device obtains network settings
       |
       v
Device can communicate on the network
```

A home router commonly provides DHCP services.

## 9. IPv6

IPv6 was developed to provide a vastly larger IP address space and
address limitations associated with IPv4 availability.

  Feature            IPv4                 IPv6
  ------------------ -------------------- ----------------------------
  Address size       32 bits              128 bits
  Representation     Decimal              Hexadecimal
  Example            192.168.1.10         2001:db8::1
  Address capacity   About 4.29 billion   Approximately 3.4 × 10\^38

Example IPv6 address:

``` text
2001:0db8:0000:0000:0000:ff00:0042:8329
```

It can be shortened by compressing consecutive zero groups:

``` text
2001:db8::ff00:42:8329
```

IPv4 and IPv6 coexist in modern networks.

## 10. IP address versus port number

An IP address identifies the network destination. A port number
identifies an application or service endpoint on that device.

Example:

``` text
192.168.1.100:8000  -> FastAPI
192.168.1.100:5432  -> PostgreSQL
192.168.1.100:6379  -> Redis
```

These are conventional default ports.

A server must also be listening on the relevant port, and network
security rules must permit the connection.

## 11. Practical development examples

### Local development

``` text
Your laptop
|
|-- React frontend: localhost:5173
|-- FastAPI backend: localhost:8000
|-- PostgreSQL: localhost:5432
```

All components can run on one physical machine and communicate through
its loopback interface.

### Cloud deployment

``` text
User's laptop
      |
      | Public internet
      v
Public-facing entry point
      |
      v
FastAPI server: 10.0.1.20
      |
      v
PostgreSQL: 10.0.1.30
```

The FastAPI and PostgreSQL addresses are private cloud-network
addresses. External users generally reach the application through a
public-facing entry point, such as a load balancer or gateway.

FastAPI can communicate with PostgreSQL over the private cloud network.

### Example database connection string

``` python
DATABASE_URL = (
    "postgresql://user:password@10.0.1.30:5432/portfolio"
)
```

Here: - `10.0.1.30` is the database host address. - `5432` is the
PostgreSQL port. - `portfolio` is the database name.

Production credentials should be stored securely, not hardcoded into
source code.

## 12. Practical commands on macOS

Display network interfaces and their configuration:

``` bash
ifconfig
```

Display the IPv4 address commonly used by the Wi-Fi interface:

``` bash
ipconfig getifaddr en0
```

Test the IPv4 loopback address:

``` bash
ping 127.0.0.1
```

Test a likely home-router address (the actual address depends on the
network):

``` bash
ping 192.168.1.1
```

## 13. Key takeaways

-   An IP address is a logical address associated with a network
    interface.
-   IP addressing helps identify destinations and route packets.
-   IPv4 uses 32 bits, divided into four 8-bit octets.
-   A subnet prefix determines the network portion of an IP address.
-   Private addresses are used inside private networks and are not
    globally routable.
-   Public addresses provide addressing for communication across the
    public internet.
-   NAT commonly allows private-network devices to share public IPv4
    connectivity.
-   `localhost` refers to the current machine.
-   DHCP automatically provides network configuration.
-   IPv6 uses 128-bit addresses.
-   IP addresses identify network destinations; ports identify
    application or service endpoints.
