# Module 00.6.06 — Queues

## 1. What is a queue?
A **queue** is an abstract data type (ADT) that follows **FIFO — First In, First Out**. The earliest item added is the first item removed. Think of a line at a service counter.

## 2. Core operations
- **Enqueue:** Add an item at the rear.
- **Dequeue:** Remove and return the item at the front.
- **Peek/front:** Read the front item without removing it.
- **Is empty:** Check whether the queue has items.
- **Size:** Get the number of queued items.

Example:
```text
Enqueue 10 → [10]
Enqueue 20 → [10, 20]
Enqueue 30 → [10, 20, 30]
Dequeue    → returns 10; queue becomes [20, 30]
```

## 3. Queue as an abstract data type
The queue ADT specifies FIFO behavior, not one required storage implementation. A queue can be implemented with a list, `collections.deque`, a circular array, or a linked list. These choices have different performance characteristics.

## 4. A simple list implementation — and its limitation
```python
queue = []
queue.append(10)
queue.append(20)
queue.append(30)

first = queue.pop(0)
print(first)  # 10
print(queue)  # [20, 30]
```
This works, but `pop(0)` takes **O(n)** because the remaining list elements shift left. Repeatedly draining a large list from the front can require O(n²) total shifting work.

## 5. Recommended Python queue: `collections.deque`
```python
from collections import deque

queue = deque()
queue.append(10)
queue.append(20)
queue.append(30)

front = queue[0]         # Peek: 10; unchanged
first = queue.popleft()  # Dequeue: returns 10

print(front)  # 10
print(first)  # 10
print(queue)  # deque([20, 30])
```

| Operation | Python list | `collections.deque` |
|---|---:|---:|
| Append at rear | Amortized O(1) | O(1) |
| Remove from front | O(n) | O(1) |
| Inspect front | O(1) | O(1) |

For ordinary FIFO processing in Python, prefer `collections.deque` over a list using `pop(0)`.

## 6. Circular queues
A **circular queue** treats a fixed-size array as if its end connects back to its beginning. It reuses slots freed at the front without shifting every item.

A common index update is:
```text
next_index = (current_index + 1) % capacity
```
When the index reaches the final position, modulo arithmetic wraps it around to index 0.

Circular queues are useful for fixed-capacity buffers. A full queue needs a policy: reject new items, block the producer, or overwrite an existing item, depending on the design.

## 7. Common queue variants
| Type | Behavior | Typical use |
|---|---|---|
| FIFO queue | Oldest waiting item first | General task processing |
| Circular queue | Reuses fixed-size storage | Bounded buffers |
| Priority queue | Selects by priority, not necessarily arrival order | Scheduling urgent work |
| Deque | Supports insertion/removal at both ends | Double-ended processing |

A priority queue is not necessarily FIFO. Priority queues and heaps are covered later in the roadmap.

## 8. AI engineering connection
A document-processing RAG pipeline might accept an upload, create a processing job, let a worker take it from a queue, extract and chunk text, create embeddings, store results, and mark the job complete or retry after failure. Queues separate API request handling from slower background work.

For real distributed systems, an in-memory `deque` is not by itself a durable task queue: it is not automatically shared across servers and its contents do not survive process restarts. Systems may use a message broker such as RabbitMQ or Apache Kafka and add acknowledgements, retries, dead-letter handling, monitoring, and idempotent workers.

## Key takeaways
1. A queue follows FIFO.
2. Enqueue adds at the rear; dequeue removes from the front; peek reads without removing.
3. `list.pop(0)` is O(n); `deque.popleft()` is O(1).
4. Circular queues reuse fixed-size storage.
5. Queues support task processing, background jobs, and asynchronous pipelines.
