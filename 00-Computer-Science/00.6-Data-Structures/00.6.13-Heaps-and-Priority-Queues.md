# 00.6.13 — Heaps and Priority Queues

## 1. Priority Queue
A **priority queue** is an abstract data type in which items are removed according to priority, not simply arrival order. A heap is a common implementation.

## 2. Binary Heap
A **binary heap** is a binary tree with two properties:

1. **Shape property:** It is a complete binary tree.
2. **Heap property:** Each parent has the required priority relationship with its children.

A complete binary tree has every level filled except possibly the last, and the last level is filled from left to right.

### Min-Heap
Each parent is less than or equal to its children. The smallest value is at the root.

### Max-Heap
Each parent is greater than or equal to its children. The largest value is at the root.

## 3. Heap Is Not a BST
A heap guarantees only the parent-child priority relationship. It does not guarantee that every value in the left subtree is smaller than every value in the right subtree, and it is not fully sorted.

A BST has a global left/right ordering rule; a heap does not.

## 4. Array Representation
A complete binary heap can be stored level by level in an array.

For zero-based indexing, for a node at index `i`:

| Relationship | Index |
|---|---:|
| Parent | `(i - 1) // 2` |
| Left child | `2 * i + 1` |
| Right child | `2 * i + 2` |

These formulas navigate the conceptual tree without explicit node pointers.

## 5. Insertion — Sift Up
1. Insert the new value at the next available array position.
2. Compare it with its parent.
3. If the heap property is violated, swap it with its parent.
4. Continue upward until the property is restored or it reaches the root.

This is called **sift up** (or bubble up). It takes `O(log n)` time because the value can travel at most the heap height.

## 6. Root Removal — Sift Down
For a min-heap:
1. Save the root value to return.
2. Move the last element to the root.
3. Remove the last array slot.
4. Compare the new root with its children.
5. Swap with the smaller child if the heap property is violated.
6. Continue downward until the property is restored.

This is called **sift down** (or bubble down). Root removal takes `O(log n)` time.

## 7. Python `heapq`
Python's `heapq` module implements a min-heap using a list.

```python
import heapq

numbers = [20, 10, 30, 5]
heapq.heapify(numbers)       # Build heap
heapq.heappush(numbers, 8)   # Insert
smallest = heapq.heappop(numbers)  # Remove smallest
```

Important operations:
- `heapq.heapify(items)`: build a heap in `O(n)`.
- `heapq.heappush(heap, item)`: insert in `O(log n)`.
- `heapq.heappop(heap)`: remove and return smallest in `O(log n)`.
- `heap[0]`: peek at the smallest in `O(1)` when non-empty.

A heap is not fully sorted. Only the root is guaranteed to be the smallest in a min-heap.

## 8. Priorities and Ties
A common tuple format is:

```python
(priority, sequence_number, task)
```

The sequence number breaks ties between equal priorities and avoids comparing task objects that may not support ordering.

To get max-priority behavior using Python's min-heap, numeric priorities can be negated.

## 9. Complexity Summary

| Operation | Complexity |
|---|---:|
| Peek at root | `O(1)` |
| Insert | `O(log n)` |
| Remove root | `O(log n)` |
| Build with `heapify` | `O(n)` |
| Search arbitrary value | `O(n)` |

A heap is optimized for repeatedly accessing/removing the top-priority item, not arbitrary lookup.

## 10. Heap vs Queue vs BST

| Structure | Removal order | Main strength |
|---|---|---|
| FIFO queue | First in, first out | Arrival-order processing |
| Priority queue | By priority | Priority-based processing |
| BST | Depends on selected operation | Ordered data and range queries |
| Heap | Root has min/max priority | Efficient top-priority access |

## 11. Uses and AI Engineering Connection
Heaps are used in task scheduling, Dijkstra's shortest-path algorithm, Top-K selection, event simulation, and priority-based work queues.

In AI engineering, they can prioritize agent tasks, background jobs, or candidate items in ranking algorithms.

An in-memory heap is not a durable distributed message broker. Production systems may also need persistence, coordination, retries, and failure recovery.

## 12. Starvation
If high-priority work continually arrives, low-priority tasks may wait indefinitely. This is **starvation**. Fairness policies or priority aging (gradually increasing the priority of waiting tasks) can reduce this risk.

## 13. Key Takeaways
- A priority queue removes items by priority, not arrival order.
- A binary heap is a common priority-queue implementation.
- A heap is a complete binary tree with a heap property.
- A min-heap keeps the smallest value at the root; a max-heap keeps the largest.
- Insertion uses sift up; root extraction uses sift down.
- Python's `heapq` is a min-heap.
- Peek is `O(1)`; insertion and root removal are `O(log n)`; `heapify` is `O(n)`.
- A heap is not a BST and is not a fully sorted array.
