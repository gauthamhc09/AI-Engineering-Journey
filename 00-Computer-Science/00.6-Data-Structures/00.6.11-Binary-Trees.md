# 00.6.11 — Binary Trees

## 1. What Is a Binary Tree?
A **binary tree** is a tree in which each node has **at most two children**, called the left child and right child. A node can have zero, one, or two children.

“At most two” does not mean every node must have exactly two children.

## 2. General Tree vs Binary Tree
- A general tree node can have any number of children, often stored in a list.
- A binary tree node has at most two child positions: left and right.
- Left and right are distinct positions; swapping them can produce a different binary tree.

## 3. Python Representation

```python
class TreeNode:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None

root = TreeNode(10)
root.left = TreeNode(5)
root.right = TreeNode(20)
root.left.left = TreeNode(3)
root.left.right = TreeNode(7)
```

Each node stores a value and references to its left and right children.

## 4. Shape Properties
If the root is at depth `0`:
- Maximum nodes at depth `d`: `2^d`.
- Maximum nodes in a binary tree of height `h`: `2^(h+1) - 1`.

For height `2`, the maximum is `2^3 - 1 = 7` nodes. This maximum occurs when all levels are filled.

## 5. Traversals

### Preorder — Root, Left, Right

```python
def preorder(node):
    if node is None:
        return
    print(node.value)
    preorder(node.left)
    preorder(node.right)
```

### Inorder — Left, Root, Right

```python
def inorder(node):
    if node is None:
        return
    inorder(node.left)
    print(node.value)
    inorder(node.right)
```

Inorder produces sorted values only when the binary tree also satisfies the Binary Search Tree (BST) ordering rule.

### Postorder — Left, Right, Root

```python
def postorder(node):
    if node is None:
        return
    postorder(node.left)
    postorder(node.right)
    print(node.value)
```

### Level-order — Level by Level
Level-order is BFS and uses a queue.

```python
from collections import deque

def level_order(root):
    if root is None:
        return
    queue = deque([root])
    while queue:
        node = queue.popleft()
        print(node.value)
        if node.left is not None:
            queue.append(node.left)
        if node.right is not None:
            queue.append(node.right)
```

## 6. Traversal Complexity
For `n` nodes:
- Preorder, inorder, and postorder: `O(n)` time and `O(h)` recursive stack space.
- Level-order: `O(n)` time and up to `O(n)` queue space.
- `h` is tree height; recursive DFS can require `O(n)` stack space in a skewed tree.

## 7. Uses
Binary trees are used in BSTs, binary heaps, expression trees, and some decision-tree representations. A BST and a heap are specific kinds of binary trees with additional rules.

## 8. AI Engineering Connection
Binary trees appear in decision paths, expression parsing, and heap-based task prioritization. AI search structures are not necessarily binary trees; graphs and specialized indexes are also common.

## 9. Key Takeaways
- Each node has at most two children.
- Preorder: Root, Left, Right.
- Inorder: Left, Root, Right.
- Postorder: Left, Right, Root.
- Level-order uses a queue.
- Full traversal takes `O(n)` time.
- Inorder is sorted only if the BST property holds.
