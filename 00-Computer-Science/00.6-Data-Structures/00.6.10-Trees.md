# 00.6.10 — Trees

## 1. What is a Tree?
A **tree** is a hierarchical data structure made of **nodes** connected by **edges**. It represents relationships where one item can contain or lead to other items.

Examples include file systems, organization charts, document outlines, and decision trees.

## 2. Core Terminology
- **Node:** An individual element.
- **Edge:** A connection between two nodes.
- **Root:** The topmost node.
- **Parent / child:** Directly connected nodes, with the parent above the child.
- **Siblings:** Nodes with the same parent.
- **Leaf:** A node with no children.
- **Internal node:** A node with at least one child.
- **Ancestor / descendant:** Nodes above / below another node along a path.
- **Subtree:** A node and all its descendants.
- **Path:** A sequence of connected nodes.

## 3. Tree Properties
For a standard non-empty rooted tree:
- There is one root.
- Every non-root node has exactly one parent.
- Every node is reachable from the root.
- A tree is connected and has no cycles.
- A tree with `n` nodes has `n - 1` edges.

## 4. Depth and Height
- **Depth:** Number of edges from the root to a node.
- **Height of a node:** Number of edges on the longest downward path from that node to a leaf.
- **Height of a tree:** Height of its root.

The root has depth `0`; a leaf has height `0` under the edge-counting convention. Some references count nodes instead of edges, so check the convention.

## 5. General Tree in Python
A general tree node can have any number of children:

```python
class TreeNode:
    def __init__(self, value):
        self.value = value
        self.children = []
```

Example:

```python
root = TreeNode("Company")
engineering = TreeNode("Engineering")
sales = TreeNode("Sales")
root.children.append(engineering)
root.children.append(sales)
engineering.children.append(TreeNode("Frontend"))
engineering.children.append(TreeNode("Backend"))
```

## 6. Tree Traversal
Traversal means visiting nodes systematically.

### Depth-First Search (DFS)
DFS explores one branch deeply before returning to another branch. This example uses preorder: visit the node, then its children.

```python
def dfs(node):
    if node is None:
        return
    print(node.value)
    for child in node.children:
        dfs(child)
```

### Breadth-First Search (BFS)
BFS visits level by level and uses a queue.

```python
from collections import deque

def bfs(root):
    if root is None:
        return
    queue = deque([root])
    while queue:
        node = queue.popleft()
        print(node.value)
        for child in node.children:
            queue.append(child)
```

## 7. Complexity
For `n` nodes:
- A full traversal takes `O(n)` time.
- Recursive DFS commonly uses `O(h)` call-stack space, where `h` is tree height; worst case `O(n)`.
- BFS can use up to `O(n)` queue space.
- Appending a child to a known parent's Python child list is typically `O(1)`.

## 8. Balanced and Skewed Trees
A **balanced** tree has levels distributed reasonably evenly. A **skewed** tree resembles a long chain. Tree height affects how much work path-based operations may require.

## 9. Uses and AI Engineering Connection
Trees are used in file systems, DOM structures, category hierarchies, decision trees, and database indexes such as B-trees and B+ trees.

In AI engineering, trees can represent document hierarchies, parsed expressions, and decision paths. Not every hierarchy or search index is a tree; some use graphs or specialized structures.

## 10. Key Takeaways
- Trees model hierarchical relationships.
- A leaf has no children.
- A standard tree with `n` nodes has `n - 1` edges.
- DFS explores deeply; BFS explores level by level.
- Visiting every node takes `O(n)` time.
- Tree height matters for many operations.
