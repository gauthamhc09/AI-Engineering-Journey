# Module 00.6.14 — Graphs

## 1. What is a graph?
A **graph** is a data structure made of **vertices (nodes)** and **edges (connections)**. It models relationships: people and friendships, cities and roads, computers and network links, or entities and their relationships.

A tree is a special graph: it is connected and has no cycles. Every tree is a graph, but not every graph is a tree.

## 2. Types of graphs
- **Undirected:** an edge has no direction. If A connects to B, B connects to A too (e.g. mutual friendship).
- **Directed:** edges have direction. A → B does not imply B → A (e.g. following someone).
- **In-degree:** number of incoming edges at a vertex.
- **Out-degree:** number of outgoing edges at a vertex.
- **Unweighted:** edges have no numerical weight.
- **Weighted:** edges carry values such as distance, cost, time, or latency.

These categories can overlap; a graph can be directed and weighted, for example.

## 3. Graph representations

### Adjacency list
Each vertex stores its neighbors. For an undirected graph with edges A-B, A-C, A-D, B-D, and C-D:

```python
graph = {
    "A": ["B", "C", "D"],
    "B": ["A", "D"],
    "C": ["A", "D"],
    "D": ["A", "B", "C"]
}
```

An undirected edge appears in both neighbor lists.

Typical complexity:
- Space: O(V + E)
- Enumerate neighbors: O(degree of vertex)
- Check an edge with a simple neighbor list: O(degree)

Adjacency lists are usually suitable for **sparse graphs**.

### Adjacency matrix
A V × V table records edges. For an unweighted graph, 1 means an edge exists and 0 means it does not. An undirected graph has a symmetric matrix.

Typical complexity:
- Space: O(V²)
- Check whether an edge exists: O(1)
- Enumerate neighbors: O(V)

Matrices can be useful for dense graphs or frequent edge-existence checks.

## 4. Python implementation
This example creates an undirected graph:

```python
class Graph:
    def __init__(self):
        self.adj = {}

    def add_vertex(self, vertex):
        if vertex not in self.adj:
            self.adj[vertex] = []

    def add_edge(self, a, b):
        self.add_vertex(a)
        self.add_vertex(b)
        self.adj[a].append(b)
        self.adj[b].append(a)


graph = Graph()
graph.add_edge("A", "B")
graph.add_edge("A", "C")
graph.add_edge("A", "D")
graph.add_edge("B", "D")
graph.add_edge("C", "D")

print(graph.adj)
```

Because `add_edge` adds both directions, this is undirected. A directed implementation would normally add only `b` to `a`'s neighbor list.

## 5. Graph traversal
Traversal visits vertices systematically. A `visited` set prevents revisiting nodes and getting stuck in cycles.

### Depth-First Search (DFS)
DFS explores one path deeply before backtracking. It uses recursion (the call stack) or an explicit stack.

```python
def dfs(graph, start, visited=None):
    if visited is None:
        visited = set()
    if start in visited:
        return

    visited.add(start)
    print(start)

    for neighbor in graph[start]:
        dfs(graph, neighbor, visited)
```

Iterative version:

```python
def dfs_iterative(graph, start):
    visited = set()
    stack = [start]

    while stack:
        node = stack.pop()
        if node in visited:
            continue

        visited.add(node)
        print(node)

        for neighbor in reversed(graph[node]):
            if neighbor not in visited:
                stack.append(neighbor)
```

Traversal order depends on neighbor ordering and stack push order.

### Breadth-First Search (BFS)
BFS visits level by level. It uses a FIFO queue; `collections.deque` provides efficient queue operations.

```python
from collections import deque

def bfs(graph, start):
    visited = {start}
    queue = deque([start])

    while queue:
        node = queue.popleft()
        print(node)

        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(neighbor)
```

Mark nodes visited when enqueuing them so they are not queued repeatedly.

With an adjacency list, a full DFS or BFS traversal is O(V + E).

## 6. Shortest paths
Choose the algorithm based on what “shortest” means:
- **BFS:** minimum number of edges in an unweighted graph.
- **Dijkstra:** shortest weighted paths when edge weights are nonnegative.
- **Bellman-Ford:** supports negative edge weights and can detect reachable negative-weight cycles.

BFS does not generally minimize total weight in a weighted graph.

A simple BFS shortest-path implementation:

```python
from collections import deque

def shortest_path(graph, start, target):
    queue = deque([[start]])
    visited = {start}

    while queue:
        path = queue.popleft()
        node = path[-1]

        if node == target:
            return path

        for neighbor in graph[node]:
            if neighbor not in visited:
                visited.add(neighbor)
                queue.append(path + [neighbor])

    return None
```

This version stores full paths for clarity. For larger graphs, parent pointers are generally more memory-efficient.

## 7. Connected components
In an undirected graph, a **connected component** is a maximal group of vertices where every vertex is reachable from every other vertex in that group. An isolated vertex is also a component.

Example:

```text
A — B       C — D       E
```

There are three components: `{A, B}`, `{C, D}`, and `{E}`.

Approach:
1. Keep a global `visited` set.
2. Loop through every vertex.
3. If a vertex is unvisited, start DFS or BFS from it.
4. The vertices reached form one component.
5. Continue until all vertices are visited.

Complexity with an adjacency list: O(V + E).

## 8. Connections to software and AI
Graphs are used in:
- Knowledge graphs and entity relationships.
- Recommendation systems.
- Graph-based retrieval and GraphRAG approaches.
- Workflow dependencies.
- Computer and communication networks.

A graph represents relationships; semantic meaning comes from the data and algorithms built around it.

## 9. Key takeaways
- A graph consists of vertices and edges.
- Graphs may be directed/undirected and weighted/unweighted.
- Adjacency lists use O(V + E) space; matrices use O(V²).
- DFS uses a stack or recursion; BFS uses a queue.
- A visited set prevents repeated visits and infinite cycling.
- BFS finds minimum-edge paths in unweighted graphs.
- Connected components are separate reachable groups in an undirected graph.
