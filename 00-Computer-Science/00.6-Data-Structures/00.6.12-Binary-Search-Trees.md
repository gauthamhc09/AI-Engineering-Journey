# 00.6.12 — Binary Search Trees (BSTs)

## 1. What Is a BST?
A **Binary Search Tree** is a binary tree with an ordering rule:
- Values in a node's left subtree are smaller than the node's value.
- Values in its right subtree are greater.
- Both subtrees follow the same rule recursively.

This module's sample implementation ignores duplicate values; other implementations may choose a different duplicate policy.

## 2. Searching
At each node:
1. If target equals current value, succeed.
2. If target is smaller, go left.
3. If target is greater, go right.
4. If the required child is absent, the value is not present.

```python
def search(node, target):
    if node is None:
        return False
    if target == node.value:
        return True
    elif target < node.value:
        return search(node.left, target)
    else:
        return search(node.right, target)
```

## 3. Insertion
Follow the same comparisons as search. Insert the value when the correct child position is empty.

```python
def insert(node, value):
    if node is None:
        return TreeNode(value)
    if value < node.value:
        node.left = insert(node.left, value)
    elif value > node.value:
        node.right = insert(node.right, value)
    return node
```

This implementation does not insert duplicates.

## 4. Deletion: Three Cases
1. **Leaf:** Remove the node's reference from its parent.
2. **One child:** Connect the parent directly to the node's only child.
3. **Two children:** Find the **inorder successor**, the smallest value in the right subtree. Replace the deleted node's value with the successor's value, then delete the successor from its original position.

The inorder successor is the next larger value in the BST's sorted order.

## 5. Complexity
Let `h` be tree height.

| Operation | Complexity |
|---|---:|
| Search | `O(h)` |
| Insert | `O(h)` |
| Delete | `O(h)` |
| Inorder traversal | `O(n)` |

- In a balanced BST, height is approximately `log₂(n)`, so search, insertion, and deletion are `O(log n)`.
- In a skewed BST, height can approach `n - 1`, making these operations `O(n)`.
- Inserting already sorted values into a basic unbalanced BST can produce a skewed tree.

## 6. Self-Balancing BSTs
AVL trees and Red-Black trees maintain controlled height using balancing rules and rotations. Their search, insertion, and deletion operations are typically `O(log n)`.

## 7. BST vs Hash Table

| Feature | BST | Hash table |
|---|---|---|
| Typical exact lookup | `O(log n)` when balanced | `O(1)` average |
| Worst-case lookup | `O(n)` if skewed | `O(n)` |
| Sorted order | Supported | Not maintained |
| Range queries | Naturally supported | Not naturally supported |

Use a hash table for fast average exact-key lookup. Use an ordered tree when sorted order or range queries matter.

## 8. Database and AI Engineering Connection
BSTs help explain ordered search and indexing. Production database indexes commonly use B-trees or B+ trees, not ordinary BSTs. Ordered structures can support range retrieval.

A BST is not a vector database or a semantic search system.

## 9. Key Takeaways
- A BST is a binary tree with a recursive ordering rule.
- Search and insertion follow one root-to-leaf path.
- Deletion has three cases: leaf, one child, two children.
- The inorder successor is the smallest value in the right subtree.
- Balanced operations are `O(log n)`; skewed operations can be `O(n)`.
- AVL and Red-Black trees are self-balancing BSTs.
