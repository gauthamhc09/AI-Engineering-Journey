# Module 00.6.05 — Stacks

## 1. What is a stack?
A **stack** is an abstract data type (ADT) that follows **LIFO — Last In, First Out**. The most recently added item is the first item removed. Think of a stack of plates: add and remove from the top.

## 2. Core operations
- **Push:** Add an item to the top.
- **Pop:** Remove and return the top item.
- **Peek/top:** Read the top item without removing it.
- **Is empty:** Check whether the stack contains items.

Example:
```text
Push 10 → [10]
Push 20 → [10, 20]
Push 30 → [10, 20, 30]
Pop     → returns 30; stack becomes [10, 20]
```

## 3. Implementing a stack with a Python list
```python
stack = []
stack.append(10)  # Push
stack.append(20)
stack.append(30)

top = stack[-1]     # Peek: 30; stack unchanged
item = stack.pop()  # Pop: returns 30 and removes it

print(top)    # 30
print(item)   # 30
print(stack)  # [10, 20]
```

**Important distinction:** `stack[-1]` reads the last element without removing it; `stack.pop()` removes and returns it. On an empty list, both operations raise `IndexError`.

## 4. Time complexity
| Operation | Typical complexity |
|---|---:|
| Push using `append()` | Amortized O(1) |
| Pop from the end | O(1) |
| Peek using `stack[-1]` | O(1) |

An individual append can take O(n) when the dynamic array resizes, even though append is amortized O(1).

## 5. Where stacks are used
- **Undo operations:** The most recent action is undone first.
- **Function calls:** Runtimes maintain call frames as functions call other functions.
- **Expression parsing/evaluation:** Operators and intermediate results can be managed with stacks.
- **Depth-first search (DFS):** A stack manages which node to explore next.

A stack is an abstract behavior, not the same thing as the program's physical or virtual memory stack. The call stack is one use of stack-like behavior.

## 6. Stack vs queue
- Stack: LIFO — last added, first removed.
- Queue: FIFO — first added, first removed.

## 7. AI engineering connection
Stacks can support DFS over graphs, parsing structured expressions, tracking undoable UI changes, and reasoning about nested execution. They are useful foundations for understanding recursion, parsers, and control flow.

## Key takeaways
1. A stack follows LIFO.
2. Push adds to the top; pop removes the top; peek reads without removing.
3. `list.append()`, `list.pop()`, and `list[-1]` provide a simple Python stack.
4. Peek and pop require a non-empty stack.
5. Stacks are useful in DFS, parsing, undo systems, and function-call behavior.
