# 00.3.11 — Python Variables and References

## Core idea
Python names are bindings to objects. Multiple names can refer to the same object, and operations differ depending on whether they mutate the object or rebind a name.

## Aliasing and mutation
```python
a = [1, 2]
b = a
b.append(3)
print(a)  # [1, 2, 3]
```
`a` and `b` refer to the same list. `append` mutates the list, so both names observe the change.

## Rebinding
```python
a = [1, 2]
b = a
b = [7, 8]
print(a)  # [1, 2]
```
The final assignment binds `b` to a new list. It does not mutate the original list referenced by `a`.

## Precise terminology
- **Mutation:** changes an existing mutable object.
- **Rebinding:** changes which object a name refers to.

## Function connection
```python
def mutate(items):
    items.append(3)

def rebind(items):
    items = [7, 8]

values = [1, 2]
mutate(values)
print(values)  # [1, 2, 3]
rebind(values)
print(values)  # [1, 2, 3]
```
The first function mutates the shared list. The second only rebinds its local parameter.

## Misconceptions
Assignment does not always copy an object. Rebinding one alias does not rebind other names. Mutation and rebinding are different operations.
