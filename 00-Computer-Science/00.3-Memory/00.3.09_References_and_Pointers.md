# 00.3.09 — References and Pointers

## How does code access an object?
```python
scores = [85, 90, 95]
```
The list needs memory. When code uses `scores`, Python resolves the name to the object it refers to. A **reference** is a way for code to access or refer to an object.

## Multiple names, one object
```python
scores = [85, 90, 95]
results = scores
results.append(100)
print(scores)
```
Output:
```text
[85, 90, 95, 100]
```
`results = scores` does not create an independent list. Both names refer to the same list object. Appending through `results` mutates the shared object, so the change is visible through `scores`.

Neither name refers to the other name; both are associated with the same object.

## What is a pointer?
At the computer-science level, a **pointer** is a value representing a memory address.

Example in C:
```c
int value = 42;
int *ptr = &value;
```
- `value` stores `42`.
- `&value` means the address of `value`.
- `ptr` stores that address.
- `*ptr` dereferences the pointer to access the value at that location.

Python differs: normal Python code does not manipulate raw memory addresses directly. Python references provide access to objects through the language's object model.

## References vs. pointers

| Concept | Pointer in C | Reference in Python |
|---|---|---|
| What it does | Represents an address | Refers to an object |
| Direct address manipulation | Possible with pointer operations | Not part of normal Python programming |
| Reassignment | A pointer can point elsewhere | A name can be rebound to another object |
| Memory operations | Pointer arithmetic/dereferencing possible | Managed through Python's object model |

CPython uses pointers internally, but Python programmers normally reason about names, references, and objects.

## Same object vs. equal contents
```python
a = [1, 2, 3]
b = a
c = [1, 2, 3]

print(a is b)  # True
print(a is c)  # False
print(a == c)  # True
```
- `a` and `b` refer to the same object.
- `c` refers to a different list with equal contents.
- `is` checks identity.
- `==` checks equality.

## Key takeaways
1. Multiple names can refer to one object.
2. `b = a` does not copy the object.
3. Mutating a shared mutable object is visible through every name that refers to it.
4. A pointer represents a memory address; Python references are used through Python's object model.
5. `is` checks identity; `==` checks equality.
