# Module 00.5.01 — What Is an Algorithm?

## Learning goal

Understand what an algorithm is, how it differs from a program implementation, and why choosing an appropriate algorithm matters.

## 1. What is an algorithm?

An **algorithm is a finite, well-defined sequence of steps for solving a problem or performing a computation**.

A typical algorithm has:
- **Input:** the data it receives.
- **Processing:** the operations it performs.
- **Output:** the result it produces.
- **Termination:** it eventually finishes, assuming the stated conditions are satisfied.

An algorithm describes the method used to solve a problem.

## 2. Algorithm vs. implementation

An algorithm is the underlying method. Python code is one way to implement it. The same algorithm can often be implemented in other programming languages, such as JavaScript, Java, or C++.

Example problem: find the largest number in a non-empty list.

Algorithm:
1. Treat the first number as the current largest.
2. Examine each remaining number.
3. If a number is larger than the current largest, update the current largest.
4. Return the largest number found.

Python implementation:

```python
def find_largest(numbers):
    largest = numbers[0]

    for number in numbers[1:]:
        if number > largest:
            largest = number

    return largest


print(find_largest([12, 5, 27, 8, 19]))
# 27
```

**Assumption:** this implementation expects a non-empty list. An empty list needs separate handling.

## 3. Trace the algorithm

For the input `[12, 5, 27, 8, 19]`:

| Number examined | Current largest |
|---:|---:|
| 12 | 12 |
| 5 | 12 |
| 27 | 27 |
| 8 | 27 |
| 19 | 27 |

The algorithm keeps track of the largest value seen so far. Each new value is compared with the current maximum.

This is an example of an algorithm maintaining state while processing input.

## 4. Choosing an appropriate algorithm

Suppose the task is to find the largest number in a list. Two possible approaches are:

- **Approach A:** Sort the entire list and select the final element.
- **Approach B:** Scan the list once, keeping track of the largest value.

Both approaches can produce the correct result. However, sorting performs additional work to arrange all numbers into order, even though the task only asks for the maximum.

For a non-empty list of `n` numbers, the scan compares each number after the first with the current maximum, requiring `n - 1` such comparisons.

Sorting is appropriate when the sorted order is also needed. Scanning is generally preferable when only the largest value is required.

**Core principle:** choose an algorithm that solves the actual problem without unnecessary work.

## 5. Why this matters in AI engineering

A RAG (Retrieval-Augmented Generation) application may need to find relevant document chunks among a large collection. Different algorithms and data structures can solve the retrieval problem, but they may require different amounts of computational work and memory.

Choosing a suitable approach helps an application handle growing datasets more effectively. The best choice depends on the task, data structure, implementation, and workload.

## Key takeaways

- An algorithm is a defined sequence of steps to solve a problem.
- Input is processed through operations to produce an output.
- An algorithm is the method; code is an implementation of that method.
- Different algorithms can solve the same problem but perform different amounts of work.
- Sorting the entire list is unnecessary if the only goal is to find its maximum.
- Understanding algorithms is foundational for analyzing computational complexity.
