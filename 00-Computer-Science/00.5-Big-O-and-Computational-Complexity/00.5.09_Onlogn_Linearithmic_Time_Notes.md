# 00.5.09 --- O(n log n): Linearithmic Time

## Core idea

Linearithmic time often appears in divide-and-conquer algorithms. An
algorithm may do roughly `n` total work at each of approximately `log n`
levels, giving total growth of **O(n log n)**.

## Example: merge sort

Merge sort divides a collection into smaller pieces, sorts them, and
merges them back together.

1.  Divide the list into halves.
2.  Continue dividing until each piece contains one element.
3.  Merge the pieces back together in sorted order.

There are approximately `log₂(n)` levels of division. At each level,
merging all pieces processes approximately `n` elements in total.
Standard merge sort therefore has O(n log n) time complexity.

## Growth comparison

    Input size `n`      `n`   `n log₂(n)` (approximately)
  ---------------- -------- -----------------------------
               100      100                           664
             1,000    1,000                         9,966
            10,000   10,000                       132,877

These values illustrate growth, not elapsed time or exact operation
counts. O(n log n) grows faster than O(n), but generally scales much
better than O(n²) for large inputs.

## Python connection: sorting

``` python
numbers = [8, 3, 6, 2, 7, 1, 5, 4]
numbers.sort()
```

Python's built-in sorting algorithm, Timsort, has O(n log n) worst-case
time complexity. It can perform better on some inputs that already
contain ordered runs.

## Doubling input size

For `n log₂(n)`, doubling the input changes the work by a factor of:
`2(log₂(n) + 1) / log₂(n)`. This is slightly greater than two: the
linear factor doubles, and the logarithmic factor increases slightly.

## AI Engineering connection

Sorting a large collection of retrieved documents by relevance score is
a common use case for efficient sorting. If only the top `k` results are
needed, a heap or selection algorithm may be more suitable than sorting
the entire collection; the best choice depends on requirements.

## Key takeaways

-   O(n log n) commonly appears in efficient divide-and-conquer
    algorithms.
-   Merge sort is a standard example.
-   Python Timsort has O(n log n) worst-case time complexity.
-   Doubling input increases n log n work by slightly more than a factor
    of two.
-   Analyze the entire task: sorting, filtering, and selecting top
    results may have different costs.
