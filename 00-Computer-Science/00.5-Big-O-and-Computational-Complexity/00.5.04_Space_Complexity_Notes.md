# 00.5.04 --- Space Complexity

## Definition

Space complexity describes how an algorithm's memory requirements grow
as its input size increases.

## Auxiliary space vs. total space

-   **Auxiliary space** is the additional working memory used by an
    algorithm, excluding the input itself.
-   **Total space** includes the input and the additional memory used by
    the algorithm. Both measurements are useful; be clear about which
    one is being discussed.

## Example: running total

``` python
def calculate_total(numbers):
    total = 0
    for number in numbers:
        total += number
    return total
```

The function processes every element but doesn't create another list.
Under the usual fixed-size model, its auxiliary space is **O(1)**. The
input list occupies O(n) space, so total space including the input is
O(n).

## Example: store every result

``` python
def double_numbers(numbers):
    result = []
    for number in numbers:
        result.append(number * 2)
    return result
```

The result list grows with the input, so auxiliary space is **O(n)**.
The cost comes from retaining one output per input element.

## Process without retaining all results

``` python
def print_squares(numbers):
    for number in numbers:
        print(number * number)
```

This doesn't create a list of all squares, so its additional working
memory is roughly constant under usual assumptions. Printing may use
internal buffers, and the original input still occupies memory.

## Example: find maximum

``` python
def find_max(numbers):
    maximum = numbers[0]
    for number in numbers:
        if number > maximum:
            maximum = number
    return maximum
```

It maintains only a small amount of additional state, so auxiliary space
is **O(1)** under the usual model---even though it may inspect every
element.

## AI Engineering connection

Memory efficiency matters when processing document chunks, embeddings,
batches, and retrieval results. Streaming or batch processing can limit
how much data is held in memory.

## Key takeaways

-   Auxiliary space excludes input; total space includes it.
-   A loop over all elements does not automatically require O(n)
    auxiliary space.
-   Retaining one output per input usually requires O(n) additional
    space.
-   Python integers can grow to represent large values, so complexity
    analyses state their assumptions.
