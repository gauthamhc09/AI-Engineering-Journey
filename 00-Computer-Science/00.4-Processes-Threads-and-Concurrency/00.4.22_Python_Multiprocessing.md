# Module 00.4.22 — Python Multiprocessing

## Why multiprocessing exists
Multiprocessing runs work in separate operating-system processes. Each process ordinarily has its own virtual address space and Python interpreter. In standard GIL-enabled CPython, separate processes can execute Python code in parallel on different CPU cores when resources permit.

Multiprocessing can be useful for CPU-bound work such as computationally expensive document preprocessing.

## Basic example
```python
from multiprocessing import Process

def process_document(name):
    print(f"Processing {name}")

if __name__ == "__main__":
    p = Process(target=process_document, args=("Document A",))
    p.start()
    p.join()
    print("All processing completed")
```

- `Process(...)` configures a child process and its target function.
- `start()` starts the child process.
- `join()` waits for it to finish.
- The `if __name__ == "__main__":` guard is important for safe process startup on platforms using the `spawn` method, including common Windows and macOS configurations.

## Separate memory spaces
Ordinary Python variables are not automatically shared between parent and child processes.

```python
from multiprocessing import Process

def change_value():
    x = 200
    print("Child:", x)

if __name__ == "__main__":
    x = 100
    p = Process(target=change_value)
    p.start()
    p.join()
    print("Parent:", x)
```

The child prints `200`, while the parent prints `100`. The child’s ordinary variable is separate from the parent’s variable. This is more than a difference in local scope: the processes have separate memory spaces for ordinary variables.

## Returning results with IPC
Processes need an explicit communication mechanism to exchange results. A `multiprocessing.Queue` is one option.

```python
from multiprocessing import Process, Queue

def calculate_result(queue):
    result = 10 * 5
    queue.put(result)

if __name__ == "__main__":
    queue = Queue()
    p = Process(target=calculate_result, args=(queue,))
    p.start()

    result = queue.get()
    p.join()

    print("Result:", result)
```

The parent receives `50` through the queue. It does not gain direct access to the child’s private memory location containing that value.

Common IPC mechanisms include `multiprocessing.Queue`, `multiprocessing.Pipe`, and `multiprocessing.shared_memory`. Shared memory is a deliberate exception to the default separation model: processes can attach to a specifically shared region, but coordination may still be needed.

## AI engineering connection
Separate processes can run independent CPU-heavy preprocessing tasks in parallel. A parent process can collect their results through IPC and continue with later pipeline stages.
