# Module 00.4 — Processes, Threads, and Concurrency

# 00.4.03 — Scheduling and Execution

## What is CPU scheduling?

CPU scheduling is how the operating system chooses which runnable thread gets CPU time and when. It helps the system make progress on multiple tasks rather than allowing one runnable thread to monopolize a core indefinitely.

## Preemption

**Preemption** means the OS can interrupt a running thread and allow another runnable thread to execute before the first thread has finished its work.

Possible reasons or triggers include:
- **Time-slice expiration:** A thread has used its allotted CPU time under the scheduling policy.
- **Higher-priority runnable thread:** Depending on the policy, a more urgent thread may be selected.
- **Blocking or yielding:** A thread may stop running because it waits for I/O or voluntarily yields. These are not necessarily preemption, since the thread may stop for its own reason rather than being forcibly interrupted.

## What happens when a thread is preempted?

1. Thread A executes.
2. A is preempted.
3. The system preserves the necessary execution context.
4. Another thread, such as B, runs.
5. A can resume later from its saved execution state.

The saved CPU context includes relevant registers and the program counter. The thread's stack and other memory generally remain in process memory; the system does not copy the entire stack every time a thread is preempted.

## AI Engineering connection

Preemption helps the OS distribute CPU time among runnable threads in a service. However, it does not guarantee equal CPU time or immediate service for every request. Runtime constraints such as CPython's GIL can add further limits, which will be covered later.

## Key takeaways

- The OS schedules runnable threads for CPU time.
- Preemption can occur before a thread finishes.
- Scheduling can be influenced by time slices, priorities, and other policy decisions.
- Blocking and yielding are distinct from forced preemption.
- A preempted thread can resume because its execution state is preserved.
