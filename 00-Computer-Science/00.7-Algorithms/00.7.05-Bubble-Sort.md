# Module 00.7.05 — Bubble Sort

## 1. What is Bubble Sort?

Bubble Sort is a comparison-based sorting algorithm. It repeatedly compares adjacent elements and swaps them when they are in the wrong order.

For ascending order:
1. Compare two neighbouring elements.
2. If the left element is greater, swap them.
3. Move one position to the right and continue.
4. After each complete pass, the largest element in the unsorted portion reaches its final position.

Example input: `[5, 3, 8, 2, 1]`.

## 2. Example passes

**Pass 1**

| Comparison | Action | Result |
|---|---|---|
| 5 and 3 | Swap | `[3, 5, 8, 2, 1]` |
| 5 and 8 | No swap | `[3, 5, 8, 2, 1]` |
| 8 and 2 | Swap | `[3, 5, 2, 8, 1]` |
| 8 and 1 | Swap | `[3, 5, 2, 1, 8]` |

The largest value, 8, is now at the end.

**Pass 2**

Start: `[3, 5, 2, 1, 8]`. The final element 8 is excluded.

| Comparison | Action | Result |
|---|---|---|
| 3 and 5 | No swap | `[3, 5, 2, 1, 8]` |
| 5 and 2 | Swap | `[3, 2, 5, 1, 8]` |
| 5 and 1 | Swap | `[3, 2, 1, 5, 8]` |

Remaining passes:
- Pass 3: `[2, 1, 3, 5, 8]`
- Pass 4: `[1, 2, 3, 5, 8]`

## 3. Python implementation

```python
def bubble_sort(numbers):
    n = len(numbers)

    for i in range(n):
        for j in range(n - i - 1):
            if numbers[j] > numbers[j + 1]:
                numbers[j], numbers[j + 1] = (
                    numbers[j + 1],
                    numbers[j]
                )

    return numbers
```

- `i` controls the passes.
- `j` controls adjacent comparisons.
- `n - i - 1` excludes the sorted suffix and prevents going beyond the last adjacent pair.
- The strict `>` comparison means equal values are not swapped.

## 4. Optimized Bubble Sort

The basic implementation performs all passes even when the input is already sorted. Add a flag to stop when a pass makes no swaps:

```python
def bubble_sort(numbers):
    n = len(numbers)

    for i in range(n):
        swapped = False

        for j in range(n - i - 1):
            if numbers[j] > numbers[j + 1]:
                numbers[j], numbers[j + 1] = (
                    numbers[j + 1],
                    numbers[j]
                )
                swapped = True

        if not swapped:
            break

    return numbers
```

If a complete pass makes no swaps, the list is already sorted.

## 5. Complexity and properties

| Case | Time | Explanation |
|---|---:|---|
| Best — optimized version | O(n) | Already sorted; one pass and no swaps |
| Average | O(n²) | Many comparisons and swaps may be needed |
| Worst | O(n²) | Reverse-sorted input requires many swaps |

**Important:** The unoptimized implementation has O(n²) time even on sorted input because it does not stop early.

- Auxiliary space: O(1).
- In-place: Yes; modifies the supplied list.
- Stable: Yes, when swapping only if left is strictly greater (`>`).
- Adaptive: The early-exit version is adaptive.

## 6. Strengths and limitations

**Strengths:** simple, stable, constant auxiliary space, and the optimized version detects already sorted input.

**Limitations:** O(n²) average and worst-case time; generally unsuitable for large datasets compared with O(n log n) algorithms.

## Key takeaways

1. Bubble Sort compares adjacent elements.
2. It swaps a pair when they are in the wrong order.
3. Each pass moves the largest remaining element to the end of the unsorted portion.
4. The inner loop gets shorter because the sorted suffix is excluded.
5. The `swapped` flag enables early termination.
6. Auxiliary space is O(1), and the algorithm is stable.
